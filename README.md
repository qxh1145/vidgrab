# VidGrab

Browser extension (MV3) that downloads HLS, DASH and direct video files, running entirely in the browser.
Project rules: [GEMINI.md](GEMINI.md). Task list: [TASKS.md](TASKS.md).

```sh
pnpm install
pnpm dev          # Chrome with hot reload
pnpm build        # → .output/chrome-mv3 (Load unpacked)
pnpm typecheck && pnpm test
```
